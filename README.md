# Sri Sai International Travels — Independent Website Demo

Premium responsive React + Vite travel-agency website, designed by MA Innovex Technologies.

## Run

```bash
npm install
npm run dev
```

Build with `npm run build` and deploy the generated `dist/` directory.

## Before publishing

1. Obtain permission from the business to publish the branded demo or activate real enquiries.
2. Replace the placeholder sitemap with a full sitemap containing your final domain; add that URL to robots.txt. Add a canonical URL and absolute Open Graph image URL for the deployed domain.
3. Confirm the office address and map pin, mobile number, opening hours, and official business name.
4. Verify the destination photography license/availability or replace illustrative Unsplash images with approved assets.
5. Obtain verified review screenshots and the official Google review link before adding review cards.
6. DEMO_MODE in `src/config.js` is true: no contact action or form submits or sends data. Set false only after explicit business approval and configure a real backend or WhatsApp handoff.
7. Prices, guaranteed departures, awards and invented testimonials have intentionally been omitted.

## SEO

Includes title and description, Open Graph/Twitter metadata, TravelAgency JSON-LD, semantic headings, responsive layout, alt text, robots.txt and sitemap.xml template. Domain-specific SEO must be completed before deployment.
